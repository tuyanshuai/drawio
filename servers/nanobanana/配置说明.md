# NanoBanana API 配置说明

## API 信息

- **API 网址**: `https://nanoapi.poloai.top`
- **认证方式**: Bearer Token
- **请求头格式**: `Authorization: Bearer {API令牌}`

## 配置步骤

### Windows PowerShell

1. **临时设置（当前会话有效）**：
```powershell
$env:NANOBANANA_API_KEY="your-api-key-here"
```

2. **永久设置（系统环境变量）**：
   - 按 `Win + R`，输入 `sysdm.cpl`，回车
   - 点击"高级"标签页
   - 点击"环境变量"
   - 在"用户变量"或"系统变量"中点击"新建"
   - 变量名：`NANOBANANA_API_KEY`
   - 变量值：你的 API 密钥
   - 点击"确定"保存
   - **注意**：需要重启 PowerShell 或命令提示符才能生效

### Linux/Mac

```bash
export NANOBANANA_API_KEY="your-api-key-here"
```

或在 `~/.bashrc` 或 `~/.zshrc` 中添加：
```bash
export NANOBANANA_API_KEY="your-api-key-here"
```

## 验证配置

启动服务后，访问 `http://localhost:8083/api/health` 检查配置是否正确。

## 安全提示

⚠️ **重要**：
- API 密钥应通过环境变量管理，不要硬编码在代码中
- 不要将包含真实 API 密钥的文件提交到 Git 仓库
