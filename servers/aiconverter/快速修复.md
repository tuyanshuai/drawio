# 快速修复环境指南

如果遇到 `Could not infer dtype of numpy.uint8` 错误，请按以下步骤操作：

## 方法 1：自动修复（推荐）

### Windows 用户

双击运行以下文件之一：
- `fix_environment.bat` （批处理脚本）
- `fix_environment.ps1` （PowerShell 脚本）

或在命令行中运行：
```cmd
fix_environment.bat
```

### 所有平台

运行 Python 脚本：
```bash
python fix_environment.py
```

脚本会自动：
1. 检查当前环境状态
2. 卸载冲突的旧版本包
3. 安装兼容的版本（NumPy 1.26.4, PyTorch 2.1.2）
4. 安装所有依赖
5. 验证安装是否成功

## 方法 2：手动修复

如果自动修复脚本不工作，可以手动执行以下命令：

```bash
# 1. 卸载可能有问题的包
pip uninstall -y numpy torch torchvision

# 2. 安装兼容版本
pip install numpy==1.26.4
pip install torch==2.1.2 torchvision==0.16.2

# 3. 安装其他依赖
pip install -r requirements.txt

# 4. 安装 SAM（如果未安装）
pip install git+https://github.com/facebookresearch/segment-anything.git
```

## 验证安装

运行以下命令验证环境是否正确：

```bash
python -c "import numpy as np; import torch; arr = np.array([1,2,3], dtype=np.uint8); tensor = torch.from_numpy(arr); print('✓ 环境正常')"
```

如果没有错误，说明环境修复成功。

## 如果问题仍然存在

1. **检查 Python 版本**：需要 Python 3.8 或更高版本
   ```bash
   python --version
   ```

2. **尝试其他 PyTorch 版本组合**：
   ```bash
   pip install numpy==1.26.4
   pip install torch==2.3.0 torchvision==0.18.0
   ```

3. **查看详细错误信息**：运行修复脚本查看具体错误

4. **检查是否有多个 Python 环境**：
   ```bash
   python -m pip list
   ```
   确保使用的 pip 和 python 来自同一个环境

## 修复后启动服务

```bash
python app.py
```

服务启动在 `http://127.0.0.1:8081`
