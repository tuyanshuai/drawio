# NumPy 版本问题手动修复指南

## 当前问题

检测到您使用的是 **NumPy 2.0.2**，但当前的 PyTorch 版本不支持 NumPy 2.x，导致 `Could not infer dtype of numpy.uint8` 错误。

## 解决方案

### 方法 1：使用 pip 降级（推荐）

如果网络正常，运行：

```bash
pip uninstall numpy
pip install numpy==1.26.4
```

### 方法 2：如果 pip 安装失败（网络/代理问题）

#### 步骤 1：清除 pip 代理配置

```bash
python -m pip config unset global.proxy
```

或者手动编辑 pip 配置文件：
- Windows: `%APPDATA%\pip\pip.ini` 或 `%HOME%\pip\pip.ini`
- 删除或注释掉 `proxy = ...` 行

#### 步骤 2：手动下载并安装

1. **下载 NumPy 1.26.4 wheel 文件**

   访问：https://pypi.org/project/numpy/1.26.4/#files

   根据您的系统下载对应的文件：
   - Windows 64位 Python 3.9: `numpy-1.26.4-cp39-cp39-win_amd64.whl`
   - Windows 32位 Python 3.9: `numpy-1.26.4-cp39-cp39-win32.whl`

2. **安装下载的文件**

   ```bash
   pip install 下载的文件路径\numpy-1.26.4-cp39-cp39-win_amd64.whl
   ```

   例如：
   ```bash
   pip install C:\Users\你的用户名\Downloads\numpy-1.26.4-cp39-cp39-win_amd64.whl
   ```

#### 步骤 3：验证安装

```bash
python -c "import numpy as np; print(np.__version__); import torch; arr = np.array([1,2,3], dtype=np.uint8); tensor = torch.from_numpy(arr); print('✓ 成功')"
```

如果看到 `1.26.4` 和 `✓ 成功`，说明修复成功。

### 方法 3：使用 conda（如果安装了 conda）

```bash
conda install numpy=1.26.4 -y
```

### 方法 4：离线安装包

如果有其他可以联网的电脑：

1. 在联网电脑上下载 wheel 文件
2. 将文件传输到当前电脑
3. 运行 `pip install 文件路径\文件名.whl`

## 验证修复

修复后，运行服务测试：

```bash
cd servers\aiconverter
python app.py
```

如果服务正常启动，说明修复成功。

## 仍然遇到问题？

1. **检查 Python 版本**：需要 Python 3.8 或更高
   ```bash
   python --version
   ```

2. **检查 pip 版本**：建议升级到最新
   ```bash
   python -m pip install --upgrade pip
   ```

3. **检查 PyTorch 版本**：
   ```bash
   python -c "import torch; print(torch.__version__)"
   ```
   如果版本过旧，可能需要升级：
   ```bash
   pip install torch==2.1.2 torchvision==0.16.2
   ```

4. **检查是否有多个 Python 环境**：
   ```bash
   python -m pip list
   ```
   确保使用的 `python` 和 `pip` 来自同一个环境。
