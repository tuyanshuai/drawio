# 医学图标库

## 概述

医学图标库提供了医疗、健康相关的图标资源，包括医疗设备、人体器官、医疗器械等。

## 当前图标

目前包含 6 个基础医学图标：

1. **听诊器** - 医疗诊断设备
2. **心脏** - 人体器官图标
3. **急救箱** - 急救医疗用品
4. **温度计** - 医疗测量设备
5. **注射器** - 医疗器械
6. **药丸** - 药品图标

## 使用建议

### 推荐优先级

1. **Health Icons** (首选)
   - 完全免费商用
   - SVG 格式，适合矢量图标需求
   - 图标数量多，质量高
   - 无需标注来源

2. **Servier Medical Art** (学术用途)
   - 高质量医学插图
   - 适合教学和学术场景
   - 需要标注来源

### 添加新图标步骤

1. **下载图标**
   - 从推荐网站下载 SVG 格式图标（优先选择）

2. **放置文件**
   - 将 SVG 文件放入 `servers/iconlibrary/data/medical/icons/` 目录

3. **更新 items.json**
   - 运行 `node servers/iconlibrary/generate-medical-items.js` 生成条目
   - 或手动在 `items.json` 中添加新条目
   - 确保 `categoryId` 设置为 `"medical"`

4. **更新 library.json**
   - 更新 `itemCount` 字段为实际图标数量

5. **测试**
   - 重启服务器
   - 在浏览器中验证图标是否正常显示

## 图标命名规范

- 使用英文小写字母
- 使用下划线分隔单词
- 例如: `stethoscope.svg`, `first_aid.svg`

## 图标质量要求

- 尺寸: 建议 100x100 或更大
- 格式: 优先使用 SVG
- 颜色: 建议使用医疗主题颜色（红色 #e74439、蓝色等）
- 清晰度: 确保图标清晰可辨

## 注意事项

- 使用任何第三方图标时，请确保遵守其许可协议
- Health Icons 为 CC0 许可，可自由使用
- Servier Medical Art 需要标注来源
- 部分网站需要注册或付费才能商用
