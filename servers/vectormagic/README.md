# VectorMagic - PNG 转 SVG 工具

一个基于 Qt 的 PNG 转 SVG 图形界面程序，模仿 VectorMagic 的核心功能。

## 功能特性

- 🖼️ 支持 PNG 图片导入和预览
- 🎨 自动矢量化转换
- 💾 导出 SVG 格式文件
- 🎯 简洁美观的 GUI 界面

## 安装

```bash
pip install -r requirements.txt
```

## 运行

```bash
python main.py
```

## 使用说明

1. 点击"选择 PNG 文件"按钮选择要转换的图片
2. 在预览窗口中查看图片
3. 点击"转换为 SVG"按钮开始转换
4. 选择保存位置保存 SVG 文件

## 技术栈

- PySide6 (Qt for Python)
- OpenCV (图像处理)
- Pillow (图像处理)
- NumPy (数值计算)
