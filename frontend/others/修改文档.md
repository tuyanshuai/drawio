# Draw.io 3D 插件开发文档

## 项目概述

本项目为 draw.io 添加了等轴测（Isometric）3D 图形支持，包括：
1. **等轴测立方体（IsoCube）** - 可旋转的 3D 立方体形状
2. **等轴测圆柱体（IsoCylinder）** - 可旋转的 3D 圆柱体形状
3. **3D 挤出效果（IsoExtrude）** - 可将任意闭合形状转换为 3D 挤出效果

所有功能均使用伪 3D 渲染技术（2D 绘制实现 3D 效果），完全兼容 draw.io 的现有架构。

---

## 新增功能

### 1. 等轴测立方体（IsoCube）

#### 功能特性
- ✅ 完整的 6 个面渲染，支持旋转和深度控制
- ✅ 基于光照的着色效果，提供真实的 3D 外观
- ✅ 支持 X/Y/Z 轴旋转（`isoRx`, `isoRy`, `isoRz`）
- ✅ 可调节深度（`isoZ`）
- ✅ 完全集成到右侧格式面板，无需弹出窗口
- ✅ 严格遵循 draw.io 的样式系统（Line、Fill 等）
- ✅ 背面可见性自动计算和隐藏

#### 技术实现
- 使用 Painter's Algorithm（画家算法）进行深度排序
- 基于法向量和光照方向的面着色
- 支持边缘可见性计算（实线/虚线）

### 2. 等轴测圆柱体（IsoCylinder）

#### 功能特性
- ✅ 平滑的圆形顶面和底面（64 个采样点）
- ✅ 多个侧面连接顶面和底面
- ✅ 与立方体相同的旋转和深度控制
- ✅ 相同的光照和着色系统
- ✅ 集成到 Isometric 调色板

#### 技术实现
- 使用 64 个采样点创建平滑圆形
- 自动生成顶面、底面和侧面
- 共享 isoCube 的旋转和渲染逻辑

### 3. 3D 挤出效果（IsoExtrude）

#### 功能特性
- ✅ 右键菜单添加"添加 3D 效果"选项
- ✅ 支持多种形状类型：
  - 矩形/圆角矩形
  - 多边形（三角形、菱形、五边形、六边形、八边形等）
  - 椭圆/圆形
  - 星形
  - 平行四边形
- ✅ 自动检测闭合形状
- ✅ 多语言支持（中文、英文、德文、法文等）
- ✅ 曲线形状侧面不绘制线条（仅填充）
- ✅ 超平滑渲染（曲线使用 512 个采样点）

#### 技术实现
- 智能轮廓点采样系统
- 根据形状类型自动选择采样策略
- 优化的光照算法，消除可见接缝
- 支持保留原始形状信息

## 技术细节

### 3D 渲染流程

#### 1. 顶点定义
```javascript
// 立方体：8 个顶点（-1 到 +1 的立方体）
var v3 = [
    {x:-sx, y:-sy, z:-sz}, // 0: 后左下
    {x: sx, y:-sy, z:-sz}, // 1: 后右下
    // ... 其他 6 个顶点
];

// 圆柱体：64 个采样点 × 2（顶面 + 底面） = 128 个顶点
for (var i = 0; i < numSamples; i++) {
    var angle = (i / numSamples) * 2 * Math.PI;
    topCircle.push({x: sx * Math.cos(angle), y: sy * Math.sin(angle), z: sz});
}
```

#### 2. 旋转变换
```javascript
function rotate(p) {
    // 按 X -> Y -> Z 顺序旋转
    return rotZ(rotY(rotX(p)));
}

function rotX(p) {
    var s = Math.sin(rx), c = Math.cos(rx);
    return {x: p.x, y: p.y * c - p.z * s, z: p.y * s + p.z * c};
}
// rotY 和 rotZ 类似
```

#### 3. 正交投影
```javascript
function project(p) {
    // 正交投影（保持平行线）
    return {x: cx + p.x, y: cy + p.y, z: p.z};
}
```

#### 4. 法向量计算
```javascript
function faceNormal(idx) {
    var a = vr[idx[0]], b = vr[idx[1]], cpt = vr[idx[2]];
    var ux = b.x - a.x, uy = b.y - a.y, uz = b.z - a.z;
    var vx = cpt.x - a.x, vy = cpt.y - a.y, vz = cpt.z - a.z;
    // 叉积计算法向量
    return {
        x: uy * vz - uz * vy,
        y: uz * vx - ux * vz,
        z: ux * vy - uy * vx
    };
}
```

#### 5. 可见性计算
```javascript
var viewDir = {x: 0, y: 0, z: -1}; // 看向 -Z 方向
var vis = (n.x*viewDir.x + n.y*viewDir.y + n.z*viewDir.z) < 0;
// 法向量与视角方向点积 < 0 表示面向观察者
```

#### 6. 深度排序（Painter's Algorithm）
```javascript
faceInfo.sort(function(a, b){ return a.z - b.z; });
// 按平均 Z 值排序，从后到前绘制
```

#### 7. 光照着色
```javascript
var light = {x: 0.35, y: -0.5, z: -0.8};
var ndotl = Math.max(0, -(nx*light.x + ny*light.y + nz*light.z));
var tint = shade(baseFill, 0.55 + 0.45 * ndotl);
```

## 使用说明

### 1. 使用等轴测立方体

1. 打开 draw.io
2. 在左侧侧边栏找到 **Isometric** 调色板
3. 点击 **Cube** 图标
4. 在画布上放置立方体
5. 选中立方体后，右侧格式面板会显示：
   - **Rot X**: X 轴旋转（-180° 到 180°）
   - **Rot Y**: Y 轴旋转（-180° 到 180°）
   - **Rot Z**: Z 轴旋转（-180° 到 180°）
   - **Depth**: 深度（0 到 2000）

### 2. 使用等轴测圆柱体

1. 在 **Isometric** 调色板中找到 **Cylinder**
2. 点击并放置到画布
3. 使用相同的旋转和深度控制

### 3. 添加 3D 效果到任意形状

1. 创建一个闭合形状（矩形、圆形、多边形等）
2. 右键点击形状
3. 选择 **"添加 3D 效果"**（或对应语言的选项）
4. 形状会自动转换为 3D 挤出效果
5. 使用格式面板调整旋转和深度

### 4. 样式控制

- **填充颜色**: 在 Style 面板设置 Fill Color
- **线条颜色**: 在 Style 面板设置 Line Color
- **线条宽度**: 在 Style 面板设置 Line Width
- **不透明度**: 在 Style 面板设置 Fill Opacity 和 Stroke Opacity
- **禁用线条**: 取消勾选 Style > Line，曲线形状的侧面线条会自动隐藏

## 已知问题和限制

### 1. 性能考虑
- 512 个采样点的曲线形状在低端设备上可能较慢
- 建议：对于不需要超平滑的场景，可以减少采样点数量

### 2. 边缘情况
- 当 `isoZ = 0` 时，形状会变成平面（仍可旋转）
- 极端旋转角度可能导致某些面不可见

### 3. 浏览器兼容性
- 需要支持 Canvas 2D API 的现代浏览器
- 已测试：Chrome、Firefox、Edge、Safari
