# 3D 棱台（Bevel）功能实现规划

## 一、功能概述

为 draw.io 的 3D 形状（isoCube、isoCylinder、isoExtrude）添加顶部棱台（Top Bevel）和底部棱台（Bottom Bevel）功能，类似 PowerPoint 中的 3D 格式设置。

**当前实现状态**：
- ✅ **isoCube**：已完成顶部和底部圆角棱台
- ✅ **isoCylinder**：已完成顶部和底部圆角棱台（已修复圆角后自身消失问题）
- ⏳ **isoExtrude**：待实现

## 二、实现原理

### 2.1 几何原理

**顶部棱台（Top Bevel）**：
- 在立方体的顶部（Y+方向）创建一个提升的顶部面
- 原始顶部面（Y=sy）向内收缩，形成倾斜的棱台边缘
- 宽度（Width）：控制顶部面在X和Z方向的收缩量（按比例缩放）
- 高度（Height）：控制棱台在Y方向的延伸高度（向上提升）

**底部棱台（Bottom Bevel）**：
- 在立方体的底部（Y-方向）创建一个降低的底部面
- 原始底部面（Y=-sy）向内收缩，形成倾斜的棱台边缘
- 宽度（Width）：控制底部面在X和Z方向的收缩量（按比例缩放）
- 高度（Height）：控制棱台在Y方向的延伸高度（向下降低）

### 2.2 数学原理

**isoCube 顶部棱台实现**：

**原始顶点**（保持不变）：
- 8个基础顶点：`(-sx,-sy,-sz)`, `(sx,-sy,-sz)`, `(-sx,sy,-sz)`, `(sx,sy,-sz)`, `(-sx,-sy,sz)`, `(sx,-sy,sz)`, `(-sx,sy,sz)`, `(sx,sy,sz)`

**顶部棱台顶点**（圆角类型）：
- 收缩比例：`scale = 1 - (topBevelWidth / Math.min(w, h))`
- 高度提升：`topBevelY = sy + topBevelHeight`
- 4个棱台角点：
  - `(-sx * scale, topBevelY, -sz * scale)` - 对应原始顶点2
  - `(sx * scale, topBevelY, -sz * scale)` - 对应原始顶点3
  - `(sx * scale, topBevelY, sz * scale)` - 对应原始顶点7
  - `(-sx * scale, topBevelY, sz * scale)` - 对应原始顶点6

**圆角过渡顶点**：
- 每条边分为16个分段（numSegments = 16）
- 每个分段从原始边到棱台边有13个圆弧顶点（numArcPoints = 12）
- 圆弧插值：`arcY = origY + (bevelY - origY) * sin(arcT * π/2)`
- 总顶点数：4个角点 + (16+1)×4条边×(12+1)个圆弧点 ≈ 884个顶点

**面（Faces）重构**：
- 顶部面：使用4个棱台角点
- 侧面：每个分段创建多个小四边形面，形成平滑圆弧过渡
- 每个边段创建12个小面（连接相邻分段的圆弧顶点）

### 2.3 渲染流程（实际实现）

1. **顶点计算阶段**：
   - 根据 bevelWidth 和 bevelHeight 计算新顶点
   - **圆角类型**：创建16个分段 × 13个圆弧点的平滑过渡
   - **圆弧插值**：使用 `sin(arcT * π/2)` 创建凸出的圆弧曲线
   - 单位转换：磅（points）→ 像素（1pt ≈ 1.33px）

2. **旋转和投影阶段**：
   - 对所有顶点应用3D旋转（isoRx, isoRy, isoRz）
   - 应用正交投影到2D平面

3. **面构建阶段**：
   - 动态构建面索引（根据是否有棱台）
   - **圆角棱台**：为每个分段创建多个小四边形面
   - 计算法向量用于光照计算

4. **可见性计算**：
   - 计算每个面的可见性（背面剔除）
   - 按深度排序（画家算法）

5. **渲染阶段**：
   - 按深度顺序渲染所有可见面
   - 应用光照着色
   - 支持填充和描边样式

## 五、技术难点

### 5.1 几何计算难点

**难点1：顶点坐标计算**
- **问题**：在3D旋转后，如何正确计算棱台顶点的收缩方向
- **解决方案**：
  - 先计算棱台顶点（在局部坐标系）
  - 再应用旋转，确保收缩方向正确
  - 使用面的法向量确定收缩方向

**难点2：面索引动态生成**
- **问题**：根据是否有棱台动态生成面，索引管理复杂
- **解决方案**：
  - 使用面工厂模式
  - 维护顶点索引映射表
  - 分阶段构建面（基础面 + 棱台面）

**难点3：圆柱体棱台** ✅ 已实现并修复
- **问题1**：圆柱体使用圆形采样点，棱台需要平滑过渡
- **解决方案**：
  - 保持64个采样点的圆形平滑度
  - 每个采样点沿半径方向创建圆弧顶点
  - 使用与isoCube相同的圆弧插值算法（sin函数）
  - 创建顶部和底部的收缩圆形面
- **问题2**：圆角后圆柱自身消失（已修复）
- **原因**：
  - `bottomCircleStartIdx` 固定为 `numSamples`，未考虑顶部圆角添加的顶点
  - 当有顶部圆角时，底部圆的索引位置计算错误
  - 侧面连接逻辑错误，导致中间侧面未正确连接
- **解决方案**：
  - 动态计算 `bottomCircleStartIdx`：在所有顶部圆角顶点添加后设置
  - 修复中间侧面连接：从原始顶部圆连接到原始底部圆（而不是从圆角顶部圆连接）
  - 修复顶部圆角侧面连接：确保从原始顶部圆开始，通过 arcVertices 正确连接

### 5.2 渲染性能难点

**难点4：顶点数量增加** ✅ 已解决
- **问题**：添加圆角棱台后顶点数从8个增加到约884个，面数大幅增加
- **解决方案**：
  - 仅在启用圆角棱台时计算额外顶点
  - 使用高效的数组操作
  - 深度排序算法已优化
- **实际性能**：渲染性能良好，实时更新流畅

**难点5：光照计算**
- **问题**：棱台面的法向量需要重新计算
- **解决方案**：
  - 为每个棱台面单独计算法向量
  - 考虑棱台倾斜角度
  - 使用插值计算渐变光照

### 5.3 UI 集成难点

**难点6：格式面板集成**
- **问题**：如何在不破坏现有格式面板结构的情况下添加新控件
- **解决方案**：
  - 使用现有的 `renderIsoFormatPanel` 模式
  - 添加到现有面板底部
  - 使用折叠面板组织控件

**难点7：实时更新性能**
- **问题**：输入变化时频繁刷新可能导致性能问题
- **解决方案**：
  - 使用防抖（debounce）延迟更新
  - 仅在失焦或回车时更新
  - 优化 `graph.refresh()` 调用

### 5.4 兼容性难点

**难点8：多种棱台类型** ⏳ 部分完成
- **问题**：PPT支持12种棱台类型，每种有不同的几何计算
- **当前状态**：
  - ✅ 已实现圆角类型（circle）
  - ⏳ 待实现角度类型（angle）
  - ⏳ 待实现斜坡类型（slope）
- **解决方案**：
  - 先实现最常用的圆角类型
  - 其他类型后续可逐步添加
  - 使用统一的插值算法框架

**难点9：单位转换** ✅ 已实现
- **问题**：PPT使用"磅"（points），需要转换为像素
- **解决方案**：
  - ✅ 定义转换比例：1磅 ≈ 1.33像素（96 DPI）
  - ✅ 在代码中自动转换：`pointsToPixels = 1.33`
  - ✅ 宽度和高度输入框使用磅作为单位

## 七、技术细节

### 7.1 棱台类型实现

**圆角棱台（Circle）** ✅ 已实现：
- **插值算法**：使用 `sin(arcT * π/2)` 创建凸出的圆弧曲线
- **顶点密度**：16个分段 × 13个圆弧点 = 平滑的圆角过渡
- **收缩比例**：线性缩放 `scale = 1 - (bevelWidth / Math.min(w, h))`
- **高度延伸**：垂直方向（Y轴）提升或降低
- **平滑特性**：侧面过渡光滑连续，无突变

**角度棱台（Angle）** ⏳ 待实现：

### 12.1 圆柱圆角问题（已修复）

**问题描述**：
- 当圆柱体添加圆角棱台后，圆柱自身消失，只显示圆角部分

**问题原因**：
1. `bottomCircleStartIdx` 固定为 `numSamples`，未考虑顶部圆角添加的顶点
2. 当有顶部圆角时，底部圆的索引位置计算错误
3. 侧面连接逻辑错误，导致中间侧面未正确连接到底部圆

**修复方案**：
1. **动态计算底部圆索引**：
   - 在添加完所有顶部圆角顶点后，动态设置 `bottomCircleStartIdx = v3.length`
   - 确保底部圆索引正确

2. **修复中间侧面连接**：
   - 当有顶部圆角（circle类型）时，从原始顶部圆（`topCircleStartIdx`）连接到原始底部圆（`bottomCircleStartIdx`）
   - 确保圆柱主体部分正确显示

3. **修复顶部圆角侧面连接**：
   - 从原始顶部圆开始，通过 arcVertices 正确连接到圆角顶部圆
   - 确保第一个面从原始顶部圆开始连接

**修复位置**：
- `frontend/main/webapp/plugins/isocube.js`
- 第1096-1098行：底部圆索引动态计算
- 第1273-1315行：顶部圆角侧面连接
- 第1343-1385行：中间侧面连接修复

**测试结果**：
- ✅ 圆柱添加圆角后正常显示
- ✅ 顶部和底部圆角同时应用正常
- ✅ 侧面过渡平滑连续
